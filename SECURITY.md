# Security policy

Found a security problem with [timfletcher.tech](https://timfletcher.tech) or this repository? Please report it privately through [GitHub private vulnerability reporting](https://github.com/NotKornFlakes/portfolio-iac/security/advisories/new), not a public issue. The site's [`security.txt`](https://timfletcher.tech/.well-known/security.txt) points to the same place.

**In scope:** the live site (TLS, security headers, DNS and email records) and the Terraform and GitHub Actions workflows in this repo.

**Out of scope:** Cloudflare's own platform, and automated scanner output with no demonstrated impact.

This is a personal site with no logins or user data. I'll reply as soon as I can.
