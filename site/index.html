SOC Home Lab: Azure Honeypots + Sentinel

Three internet-facing honeypots feeding Microsoft Sentinel, used to write and test real detections against real attackers.

  • Deployed Windows RDP, Cowrie SSH and Endlessh honeypots with Azure Monitor Agent and custom log tables; captured 1.24M attempts from 75 IPs with zero compromises.

Sentinel SOAR: Automated Brute-Force Response

A Logic App playbook that enriches Sentinel incidents with threat intel and blocks high-risk IPs automatically.

  • Integrated Sentinel, the AbuseIPDB API and the Azure REST API, running under a least-privilege managed identity.
  • Cut triage to ~12 seconds (8–18 s) from 10–15 minutes; blocked IPs made zero further attempts.
  • Per-IP grouping reduced 65 alerts to 6 incidents, about 91% less noise for analysts.
